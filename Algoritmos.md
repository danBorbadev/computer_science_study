Esse é o assunto principal, talvez a base da [[Ciência da computação]] e do [[Pensamento Computacional]], os algoritmos é uma sequência finita e organizada de instruções para resolver um problema ou atingir um objetivo.

Pense em uma receita de bolo:

1. Pegar os ingredientes;
2. Misturar.
3. Colocar no forno;
4. Esperar;
5. Retirar o bolo;

Isso é um algoritmo, é uma sequência de passos que transforma uma entrada em um resultado.

Podemos trazer isso para computação, resolvendo problemas desde somar dois números, e resolver problemas mais complexos.

É importante ressaltar que o algoritmo não é necessariamente um código, ele é apenas a lógica. Antes de começar a escrever códigos precisamos definir a **lógica**, exemplo:
	*Receba dois números, some-os e mostre o resultado*

É, basicamente, o **raciocínio por trás do programa.**

É importante ressaltar a conectividade de algoritmos com o [[Pensamento Computacional]], pois os mesmos envolvem entender o problema, quebrar em pequenas etapas, criar uma lógica para resolvê-lo, algoritmo, implementar uma linguagem, programa.

Outra coisa muito importante, é que existem várias formas de resolver um problema usando algoritmos, algumas formas são mais rápidas, outras são mais lentas. É importante entender e organizar a estrutura para que a performance seja a melhor possível para resolver o problema, para isso existe a [[Notação BIG O]].
