É uma tabela de correspondência entre números e caracteres.
Por exemplo: 

65 → A
66 → B
67 → C
97 → a
98 → b
48 → 0

e como o computador trabalha com o [[Sistema Binário]]:

``` 
65 → 01000001 → A
```

A ASCII uma convenção, que diz:
	Quando você encontrar o número 65,interprete como A
	 É como um dicionário:
	 `65 = A`
