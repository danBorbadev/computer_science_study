O sistema binário é a linguagem básica que permite que os computadores representem informações.
Vamos pensar em uma lâmpada:
	 apagada = 0
	 acesa = 1

Um computador possui bilhões de componentes eletrônicos capazes de trabalhar com estados físicos que podemos representar como 0 e 1.

Temos:
Problema -> algoritmo -> programa -> computador

E na camada mais baixa:
Programa -> instruções -> bits (0 e 1) -> eletricidade -> hardware 

O binário é o fundamento físico/lógico da computação digital, porém não precisamos programar em binário, as linguagens e sistemas envolvidos pela [[Ciência da computação]] escondem essa complexidade.
